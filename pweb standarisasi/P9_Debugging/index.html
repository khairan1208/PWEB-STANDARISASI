Debugging Challenge (Bab 6)

Halaman ini dirancang untuk latihan membaca pesan error dan memperbaiki bug JavaScript.

Silakan buka Developer Tools (F12) lalu pilih tab Console untuk melihat hasil eksekusi kode serta pesan galat yang muncul.

Petunjuk: Periksa berkas JavaScript untuk melihat perbedaan antara kode yang bermasalah dan kode yang telah diperbaiki.
